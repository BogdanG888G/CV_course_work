# Как устроена работа

## Постановка

Объект — RGB-фотография, целевая переменная — одна из 15 категорий.
Например, `sitting`, `running`, `using_laptop`. Модель не определяет положение
человека рамкой и не отслеживает его во времени. Если на фото несколько людей
с разными действиями, один ответ на весь кадр может быть неоднозначным.

## Исходная модель

ResNet18 извлекает карту признаков размером примерно 512 × 7 × 7 при входе
224 × 224. Стандартный pooling усредняет каждую карту по пространственным
координатам. Получается вектор из 512 признаков, который линейный слой
преобразует в 15 логитов. Cross-entropy используется для обучения;
softmax преобразует логиты в вероятности при предсказании.

ImageNet-веса дают начальное представление о визуальных признаках.
Мы дообучаем всю сеть на действиях человека, а не используем готовую
ImageNet-классификацию. Предобучение разрешено требованиями уровня «4».

## Модификации

### GeM

Для карты с неотрицательными активациями:

\[
g_c = \left(\frac{1}{HW}\sum_{h,w}x_{c,h,w}^{p}\right)^{1/p}.
\]

При p=1 это среднее; больший p усиливает влияние сильных активаций.
Здесь p — один общий обучаемый параметр, который задаётся через softplus
и ограничивается сверху для численной устойчивости. Начальное значение
около 3. Эта замена меняет способ объединения признаков.
Результат может ухудшиться: усиление локальной активации способно выделить
фон или предмет, а не действие человека.

### Average + max

Среднее отражает распределённые признаки, максимум — наиболее сильный
отклик. Конкатенация даёт 1024 признака. Поэтому линейная голова становится
шире. Это нужно явно указать при сравнении числа параметров.

### Spatial attention

Свёртка 1×1 получает одну карту оценок, softmax нормирует их по пространству.
Итоговый признак — взвешенная сумма исходных признаков. В начале веса равны,
поскольку свёртка инициализирована нулями; далее сеть обучает веса областей.
Это лёгкий пространственный механизм внимания, а не Transformer.

## Честная оценка

Train обновляет веса. Validation выбирает эпоху и вариант сети.
Test используется один раз после выбора. Все исходные и модифицированные
варианты обучаются на одних данных. Копии не должны попадать в разные выборки.
Проверка pHash уменьшает риск утечки, но не доказывает отсутствие всех
семантически похожих изображений.

Macro F1 — среднее F1 отдельных классов. Accuracy — доля верных ответов.
Заранее фиксируем macro F1 основной метрикой и не меняем её после просмотра
результатов. Даже на сбалансированных исходных данных полезно понимать,
насколько хорошо распознаётся каждый класс.

## Где искать код

| Файл | Ответственность |
|---|---|
| har/prepare.py | Проверка изображений, группы копий, разбиение |
| har/data.py | Чтение изображений и преобразования |
| har/models.py, har/pooling.py | Готовая ResNet18 и собственные pooling-модули |
| har/engine.py | Seed, DataLoader, одна эпоха и метрики |
| har/train.py | Обучение, лучшие веса, MLflow, графики |
| har/select.py | Сравнение по validation и фиксация модели |
| har/evaluate.py | Итоговый test, матрица ошибок и примеры |
| har/api.py | Загрузка модели и HTTP API |
