# Состояние проекта — 12 ноября 2026

## Выполнено и проверено

- Проверены и декодированы все 12 600 размеченных изображений; нечитаемых нет.
- Найдена 141 группа совпадающих/близких изображений по SHA-256, хешу пикселей
  и pHash с порогом Hamming distance ≤ 4. Не все такие группы являются точными
  копиями; визуальная проверка подозрительных групп остаётся необходимой.
- Конфликтов меток в найденных группах нет.
- Сохранены train/validation/test: 8 819 / 1 886 / 1 895 изображений.
- Независимо проверено отсутствие пересечений путей, файловых и пиксельных
  хешей, а также pHash-соседей в пределах порога между выборками.
- Тесты подготовки данных: 2 прошли. Проверяют воспроизводимость, группировку
  копий, исключение конфликтов/повреждённых файлов и индекс Hamming distance.
- Тесты pooling-модулей: 3 прошли. Проверяют начальную эквивалентность attention
  среднему, свойства GeM, наличие градиента его параметра и комбинацию avg/max.
- Тесты выбора модели: 3 прошли. Проверяют требование трёх модификаций при
  отсутствии улучшения, сравнимость кода/условий и запрет выбора smoke-весов.
- CPU- и GPU-конфигурации проходят `docker compose config --quiet`.
- Python-файлы компилируются без синтаксических ошибок.

## Реализовано, но ещё не проверено полным запуском

Обучение ResNet18, MLflow, сравнение вариантов, итоговая test-оценка,
FastAPI, сборка Docker-образа и интеграция контейнеров.

Причины ограничения проверок:

- Docker CLI и Compose установлены, Linux engine недоступен; попытка запуска
  через `docker desktop start` не привела к доступному engine и была остановлена.
- Локальный PyTorch — 2.0.1+cpu, CUDA недоступна; torchvision отсутствует.
- Локальный MLflow 2.8.1 не импортируется из-за несовместимого protobuf 6.33.4.
- Попытка установки совместимых пакетов в отдельное окружение остановилась
  на сетевой ошибке DNS. Глобальные зависимости не изменялись.
- Тесты полной сети/API не смогли импортировать torchvision и не выполнены.

Docker использует отдельный зафиксированный набор зависимостей из
`requirements.txt`, включая PyTorch 2.5.1 / torchvision 0.20.1 и MLflow 2.19.0.
Его работоспособность нужно проверить сборкой и тестами в Docker.

## Чего пока нет

Полноценных обученных моделей, научных результатов по качеству,
финальных весов для API, заполненного отчёта и подтверждения темы преподавателем.
Синтетические тесты и smoke-режим не заменяют обучающие эксперименты.

Следующее действие: запустить Linux engine Docker Desktop, выполнить сборку
и тесты из README, затем smoke-проверку связки обучения с MLflow.
